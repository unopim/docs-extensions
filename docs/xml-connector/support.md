# Support

Need help with the UnoPim XML Connector? Email us at [support@webkul.com](mailto:support@webkul.com) or raise a ticket on our [HelpDesk System](https://webkul.uvdesk.com/en/).

It helps to include:

- Your UnoPim version and the connector version (for example UnoPim 3.1.3, XML Connector 1.3.0)
- The import type and a sample of the XML file
- The error shown in the Job Tracker, or the downloaded full report
